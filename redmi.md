## 4. Ошибка latin-1 кодировки

**Пользователь:** `API 502: {"error": "'latin-1' codec can't encode characters in position 7-10..."}`

**Ассистент:** Причина — `urllib` отправлял HTTP-заголовки в `latin-1`, а в `Authorization` попадали не-ASCII символы (смарт-кавычки или BOM из `.env`). Чинил в `main.py`:
- `encoding="utf-8"` → `encoding="utf-8-sig"` (съедает BOM)
- Добавлен `_STRIP_QUOTES` со смарт-кавычками `"" '' «»`
- `Authorization` отправляется как UTF-8 bytes
- При старте проверка `API_KEY.isascii()` с warning

## Финальная структура проекта

```

├── .env                    # секреты (в .gitignore)

├── cert.pem + key.pem      # self-signed сертификаты (если USE_HTTPS=true)
└── src/
    ├── core.js             # промпты, валидация, патч рендера, бейдж, тарифы, mobile-гамбургер
    ├── app.js              # инициализация, навигация, AI-edit UI, mobile-toggle
    ├── render.js           # рендер слайдов (оригинальный)
    ├── gallery.js          # галерея per-user
    ├── themes.js           # темы оформления
    ├── help.js             # помощь
    ├── export-pdf.js
    ├── export-pptx.js
    └── export-odp.js
```
