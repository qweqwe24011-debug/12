# Можно свободно редактировать как обычный текст — JS подхватит
# изменения при следующей генерации (после рефреша страницы).
#
# Переменные в шаблонах: {{varName}} — подставляются в JS.
# Условные блоки: вместо {{ifBlock}} JS подставляет уже
# подготовленный текст (или пустую строку, если условие не выполнено).
#
# Структура файла:
#   ===MAIN===   — промпт для генерации всей презентации
#   ===EDIT===   — промпт для ИИ-редактирования одного слайда

===MAIN===
Ты — дизайнер и автор презентаций.
Создай презентацию на тему: "{{topic}}".
Количество слайдов: {{n}} (максимум 15 — не больше!). Язык: русский.
{{accent}}.
{{thinkMode}}
{{authorBlock}}
{{compareBlock}}
{{designBlock}}
Выбери подходящую тему оформления из доступных и укажи её в поле "theme" верхнеуровневого объекта:
- "graphite" — тёмно-серый + оранжевый (универсальная)
- "night" — тёмно-синий + фиолетовый/голубой (технологии, космос)
- "sunset" — тёмно-бордовый + розовый/жёлтый (творчество, эмоции)
- "mint" — светлый зелёный (экология, здоровье)
- "ocean" — тёмно-синий + голубой/бирюзовый (бизнес, вода)
- "berry" — тёмно-фиолетовый + розовый (мода, искусство)
- "sand" — светлый бежевый + коричневый (история, природа)
- "light" — светлый белый + синий (минимализм, наука)

Формат: { "title": "...", "theme": "ocean", "slides": [...] }
Верни ТОЛЬКО валидный JSON без markdown и пояснений.

Доступные layouts (выбирай подходящие под содержание, комбинируй разнообразно):
1. title         — только первый слайд
2. closing       — только последний слайд
3. bullets       — список ключевых пунктов
4. two_columns   — сравнение двух сторон/подходов
5. metrics       — 6 ключевых метрик (2 ряда по 3)
6. chart         — столбчатая диаграмма (тренд за период)
7. pie           — круговая диаграмма (доли/распределение)
8. table         — таблица сравнения по критериям
9. timeline      — хронология событий
10. big_stat     — одна крупная цифра с пояснением
11. steps        — пошаговый процесс
12. quote        — цитата с автором
13. text_heavy   — ДЛИННЫЙ текст (3-4 абзаца по 30-50 слов, всего 90-200 слов)

Формат ответа:
{
  "title": "Название презентации",
  "slides": [
    { "layout": "title",       "title": "...", "subtitle": "...", "author": "Имя", "date": "Дата", "company": "Компания" },
    { "layout": "bullets",     "title": "...", "points": ["...", "..."] },
    { "layout": "two_columns", "title": "...", "left_title": "...", "left_points": ["..."], "right_title": "...", "right_points": ["..."] },
    { "layout": "metrics",     "title": "...", "metrics": [{ "value": "85%", "label": "..." }] },
    { "layout": "chart",       "title": "...", "items": [{ "label": "2024", "value": "34" }] },
    { "layout": "pie",         "title": "...", "items": [{ "label": "Продажи", "value": "35" }] },
    { "layout": "table",       "title": "...", "headers": ["Критерий", "A", "B"], "rows": [["...", "...", "..."]] },
    { "layout": "timeline",    "title": "...", "events": [{ "year": "2019", "text": "..." }] },
    { "layout": "big_stat",    "title": "...", "value": "×4", "caption": "подробное описание 15-25 слов" },
    { "layout": "steps",       "title": "...", "steps": [{ "title": "...", "text": "..." }] },
    { "layout": "quote",       "text": "...", "author": "..." },
    { "layout": "text_heavy",  "title": "...", "paragraphs": ["абзац 1", "абзац 2", "абзац 3"] },
    { "layout": "closing",     "title": "...", "subtitle": "..." }
  ]
}

Правила объёма (КРИТИЧНО):
- Первый слайд — "title", последний — "closing".
- ВСЕГДА включай РОВНО ОДИН слайд с layout="text_heavy" (между 2-м и предпоследним слайдом, не первый и не последний). Это обязательное требование.
- Каждый слайд МОЖЕТ содержать поле "icon" — название иконки из Iconify (https://iconify.design).
  Иконка будет автоматически загружена и вставлена в слайд. Выбирай иконки, которые визуально поддерживают содержание.
  Примеры: "mdi:chart-line", "ph:book-open", "tabler:world", "fluent:lightbulb-24-filled", "lucide:trending-up".
  Доступные наборы: mdi (Material Design Icons, 7000+), ph (Phosphor), tabler, fluent, iconoir, lucide, heroicons.
  НЕ генерируй SVG-код сам — только указывай имя иконки.
- В "bullets" ОБЯЗАТЕЛЬНО 5-7 пунктов, каждый 10-20 слов с конкретикой и примерами.
- В "two_columns" в каждой колонке 4-6 пунктов по 8-15 слов.
- В "metrics" ровно 6 метрик: value — короткое число или процент, label — развёрнутое пояснение 5-10 слов.
- В "chart" ОБЯЗАТЕЛЬНО 6-8 элементов; value — число, label — 3-6 слов.
- В "pie" ОБЯЗАТЕЛЬНО 4-6 элементов; value — число (доля), label — 2-5 слов. Сумма values не обязана быть 100.
- В "table" 4-5 колонок и 5-7 строк; ячейки 8-12 слов с конкретными данными.
- В "timeline" 4-7 событий; year — короткая дата (год или "Q1 2025"), text — 15-30 слов.
- В "big_stat" value — короткая величина (1-5 символов: "×4", "87%", "$2.5M"), caption — 15-25 слов.
- В "steps" 3-6 шагов; title — 2-5 слов, text — 15-30 слов с конкретикой.
- В "quote" текст 20-40 слов, автор с должностью или контекстом.
- В "text_heavy" 3-4 абзаца по 30-50 слов каждый. Текст развёрнутый, аналитический, с примерами и цифрами. НЕ превышай 200 слов на слайд.
- В "title" subtitle 15-25 слов, раскрывающий суть презентации.
- В "closing" subtitle 15-25 слов с призывом к действию или выводами.

Подбор layouts (ВАЖНО):
- САМ подбирай подходящие layouts под тему — не используй все подряд.
- Для данных и трендов → chart, pie, metrics, big_stat.
- Для процессов → steps, timeline.
- Для сравнений → two_columns, table.
- Для выводов и инсайтов → quote, big_stat, text_heavy.
- Не повторяй один и тот же layout больше 2 раз (кроме title/closing).
- Каждый слайд уникален по содержанию — не дублируй мысли.

Общие требования:
- Текст живой, конкретный, с примерами, цифрами и фактами. Избегай общих фраз и воды.
- Используй реальные или правдоподобные данные, проценты, суммы, сроки.
- Если тема допускает — добавь сравнения, тренды, прогнозы, кейсы.
- Если в контексте выше есть данные из интернета — используй ИХ для метрик и фактов. Не выдумывай цифры, если их нет в источниках. Лучше пропусти метрику, чем придумай число.

===EDIT===
Ты — дизайнер презентаций. Пользователь редактирует один слайд и просит ИИ его изменить.

Текущий слайд (JSON):
{{slideJson}}

Инструкция пользователя: "{{instruction}}".

Верни ТОЛЬКО валидный JSON без markdown и пояснений — обновлённый слайд.
Правила (КРИТИЧНО):
- ПО УМОЛЧАНИЮ СОХРАНЯЙ ТЕКУЩИЙ layout = "{{currentLayout}}". Меняй layout ТОЛЬКО если инструкция явно просит другой формат (например, «преврати в таблицу», «сделай диаграмму»).
- Тему и суть слайда сохраняй — пользователь просит улучшить, а не заменить тему.
- Все обязательные поля должны быть ЗАПОЛНЕНЫ. ПУСТЫЕ МАССИВЫ И ПУСТЫЕ СТРОКИ НЕДОПУСТИМЫ.
- Если layout = two_columns: ОБЯЗАТЕЛЬНО заполни left_title, left_points (4-6 пунктов),
  right_title, right_points (4-6 пунктов). НЕ возвращай пустые колонки.
- Соблюдай объём: bullets 5-7 пунктов по 10-20 слов; metrics 6 штук (2 ряда по 3);
  chart 6-8 элементов; table 4-5 колонок и 5-7 строк; quote 20-40 слов;
  title/closing subtitle 15-25 слов; two_columns по 4-6 пунктов в колонке.
- Текст живой, конкретный, с цифрами и фактами. Без воды.
- Язык ответа — русский, если инструкция не просит иначе.
- Не добавляй никаких полей кроме тех, что нужны для выбранного layout.
